## 🚀 Usage

### Quick Start

```bash
# 1. Start dev server
yarn dev

# 2. Generate screenshots (new terminal)
yarn screenshots

# 3. View results
open screenshots/index.html
```

### First Time Setup

```bash
# Install Playwright browsers (one-time)
npx playwright install chromium

# Update test credentials in script
# scripts/screenshot-generator.mjs line 25-28
```

## 🎨 Customization Options

### Add New Screens

Edit `SCREENS` array in `screenshot-generator.mjs`:

```javascript
{
  name: 'my-screen',
  path: '/my-path',
  requiresAuth: true,
  waitFor: 'h1',
  description: 'My Screen Name'
}
```

### Change Viewport Sizes

```javascript
const CONFIG = {
  viewport: { width: 1920, height: 1080 }, // Desktop
  mobileViewport: { width: 375, height: 812 }, // Mobile
};
```

### Adjust Quality

```javascript
deviceScaleFactor: 2; // 1=normal, 2=retina, 3=ultra
```

### Screenshot Mode

```javascript
fullPage: true; // true=entire page, false=viewport only
```

## 🔧 Technical Details

### Technologies Used

- **Playwright** - Browser automation
- **Chromium** - Headless browser
- **Node.js ESM** - Modern JavaScript modules
- **HTML/CSS/JS** - Viewer interface

### Configuration

```javascript
{
  baseURL: 'http://localhost:5173',
  screenshotDir: './screenshots',
  viewport: { width: 1920, height: 1080 },
  mobileViewport: { width: 375, height: 812 },
  testCredentials: {
    email: 'test@xcarbon.com',
    password: 'Test123!@#'
  }
}
```

### Performance

- Average capture time: ~2-3 seconds per screenshot
- Total run time: ~3-5 minutes for all screens
- Parallel processing: Not currently implemented (sequential)
- Headless mode: Yes (faster, no UI)

The script handles:

- ✅ Login failures (skips auth screens gracefully)

- ✅ Network timeouts (configurable waits)
- ✅ Theme toggle issues (localStorage fallback)
- ✅ Screenshot failures (logs and continues)
